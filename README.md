# Σχολή Tae Kwon Do Δαβίδ 🥋

The official website for **David's Taekwondo School**, located in Rethymno, Crete. 

**Live Site:** [david-tkd.gr](https://david-tkd.gr)

## Built With
- HTML5
- CSS3
- JavaScript

##  Overview
A responsive and clean website built to establish the online presence of the dojo. It provides essential information to current and prospective students, including:
- Martial arts programs and classes.
- Weekly training schedules.
- Contact details and location mapping.
- Local SEO optimization.
